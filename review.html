第一、二章要点清单

第一章课件不在这批文件里。下面几条来自第二章 PDF 第 69–71 页，标题就是「第一、二章 晶体结构、晶体衍射要点复习」。

  • 晶体结构 = 布拉菲格子 + 基元。格子、格点、原胞、维格纳–塞茨原胞、复式格子要能分开说。
  • 基本特征是周期性。配位数清单：12、8、6、4、3、2。面心立方取 12，体心立方取 8，简单立方取 6，金刚石取 4。
  • 要能画或写出的结构：简立方、体心立方、面心立方、六角密积、氯化钠、氯化铯、金刚石（闪锌矿）、钙钛矿。钙钛矿的具体堆法在这份第二章课件里没有展开，习题第 11 题问的就是它。
  • 晶向指数、以原胞基矢定义的晶面指数、以晶胞基矢定义的密勒指数，三者不要混用坐标轴。
  • 对称性清单：8 种基本对称操作、32 种点群、230 种空间群；七大晶系、14 种布拉菲格子。
  • 衍射部分的入口：倒格子、布里渊区、三种探针、衍射条件、散射因子、结构因子、消光条件。

第二章 晶体中的衍射

目录在 PDF 第 2 页：晶体的衍射，倒格子和布里渊区，晶体的衍射条件，原子散射因子和几何结构因子。

2.1 三种探针

原子间距约 10−10 m，探针波长也要在这个量级。X 射线光子的最短波长由加速电压决定，课件的例子是约 40 kV 对应约 0.3 Å，和 λ(Å) ≈ 12400 / V(V) 一致。电子波长由 λ = h/p、p²/2m = eV 决定；课件比较说，约 150 V 就能得到约 1 Å 的电子波，同样波长的 X 射线大约要 12 kV。

散射来源课件强调的用途课件强调的限制
X 射线核外电子穿透好，适合块体物相。峰位给出晶胞尺寸和形状，峰强给出原子种类和坐标。对氢等轻原子弱，不能测磁结构。
电子原子核和电子的库仑场散射强，适合薄膜和微区。准晶 Al–Mn 的二十面体相就是电子衍射看到的。穿透浅。课件给的量级：50 kV 正入射约 500 Å，倾斜后约 50 Å。
中子原子核，另加磁矩轻原子和磁结构。约 0.1 eV 的中子波长约 1 Å。依赖反应堆或散裂源。

2.2 倒格子和布里渊区

倒格点 Kh = h1b1 + h2b2 + h3b3。每个布拉菲正格子对应一个倒格子，倒格子本身也是布拉菲格子。课件第 72 页把正倒格子关系收成五条：

  1. ai · bj = 2π δij。
  2. 倒格子原胞体积是正格子原胞体积倒数的 (2π)3 倍：Ω Ω* = (2π)3 = 8π3。
  3. Kh 是晶面族 (h1h2h3) 的法线。
  4. |Kh| = 2π / dh1h2h3。晶面越密，d 越小，倒格矢越长。
  5. 正格矢和倒格矢满足 Rl · Kh = 2πμ，μ 为整数。满足这个关系时，一个是正格矢，另一个就是倒格矢。

简单立方的倒格子仍是简单立方。面心立方的倒格子是体心立方，第一布里渊区是 14 面的截角八面体。体心立方的倒格子是面心立方，第一布里渊区是菱形十二面体。简单六方的倒格子仍是六方，两者转开 30°。

布里渊区的做法：从某个倒格点向其余倒格点作倒格矢的垂直平分面。第一布里渊区是不过任何中垂面的那一块，也就是倒格子的维格纳–塞茨原胞。第 n 区恰好跨过 n−1 个中垂面。各区体积相同，都等于倒格子原胞体积，都可以平移整数个倒格矢回到第一区。第一区也叫简约布里渊区。

立方晶面间距可以直接用来做习题第 1 题：dhkl = a / √(h²+k²+l²)，所以简单立方的 d111 = a/√3。

2.3 衍射条件

各原胞之间的干涉加强写成倒空间的衍射方程：散射波矢和入射波矢相差一个倒格矢，k − k0 = Kh。这就是劳厄条件。厄瓦尔德作图把同一条件画成球面：以入射波矢的起点为球心，落在球面上的倒格点才发生反射；该倒格矢的中垂面就是对应晶面。

倒格矢长度 |K| = 2π/d 把劳厄条件和布拉格定律连在一起。一级衍射的线段上没有别的倒格点；m 级衍射的线段里会有 m−1 个倒格点。

2.4 散射因子、结构因子和消光

三个层次和习题第 3 题一一对应：一个原子的散射能力是原子散射因子；一个原胞里不同原子的干涉是几何结构因子；原胞和原胞之间的干涉是上一节的衍射条件。原子里的电子分布会使原子的散射弱于 Z 个自由电子的简单相加。

已知原子排列可以判断哪些衍射消失，反过来也可以由强度推断原胞里的原子排列。课件给出的元素晶体消光规律：

  • 体心立方：h+k+l 为奇数时结构因子为零；为偶数时 F = 2f。
  • 面心立方：只有 h、k、l 全奇或全偶才出现衍射；奇偶混杂的反射消失。
  • 金刚石：在面心立方条件之上再乘相位因子。全奇可以出现；全偶且 (h+k+l)/2 也是偶数才出现。

课件还有一个一维复式链的例子：A、B 等间距交替，入射垂直于链。同种原子干涉加强的条件是 a cosθ = mλ。m 为奇数时强度正比于 |fA − fB|2；若 fA = fB，奇数级消光。KCl 那道习题用的就是「两种原子散射因子几乎相等」这一情况，放在面心立方的氯化钠型格子上。

第三章 晶体的结合

这一章从能量说明原子为什么会聚成晶体，并讨论五种结合。课件把结合能写成 Uc = U0 − UN：U0 是晶体总能量，UN 是 N 个自由原子（离子）的能量。平衡间距处晶体内能取负的极小值 UC，课件把 |UC| 叫内聚能。|UC| 越大，晶体越稳定，熔点也越高。

3.1 吸引、排斥和弹性模量

绝对零度、不受外力时，原子停在 r0。r > r0 时合力为吸引，r < r0 时合力为排斥。排斥是短程力，随距离衰减得比吸引快。能量零点取在 r → ∞，课件把内能写成

U(r) = −A / rm + B / rn，A、B、m、n > 0，且 m < n。

r0 由 dU/dr = 0 决定。离子晶体取 m = 1，并把吸引项的系数写成与马德隆常数有关的 NMe2/(4πε0)。氯化钠的排斥指数 n = 8，平衡时排斥项的大小是吸引项的 1/8。

体积弹性模量由热力学定义，再写成内能对体积的导数。平衡体积 V0 = N β r03，β 由结构决定。课件列出的几何因子：

结构β课件给出的近邻关系
简单立方1r0 = a
面心立方√2 / 22r0 = √2 a
体心立方4√3 / 92r0 = √3 a
氯化钠型22r0 = a
氯化铯型8√3 / 92r0 = √3 a
闪锌矿型16√3 / 94r0 = √3 a

闪锌矿这一行和 GaAs 的晶格常数题用的是同一几何关系：最近邻沿体对角线的 1/4。

五种结合

  • 离子结合，§3.2。 先把中性原子变成分开的离子，再让正负离子聚成晶体。库仑吸引是长程的，靠马德隆求和；排斥用 r−n。
  • 范德瓦耳斯结合，§3.3。 分子晶体。课件按近邻、次近邻、第三近邻把一对原子的势能加总，面心立方要分别数这几层邻居。
  • 共价结合，§3.4。 饱和性写得很明确：一个电子配对之后不能再和第三个电子配成同样的键。大量原子靠拢时能级展宽成能带，这一句在结合这一章就出现了。
  • 金属结合，§3.5。 晶体里有大量自由电子，因此导电、导热好。结合来自负离子实和公共电子气。
  • 氢键，§3.6。 氢只有一个电子，电离能却不低。冰里 H 与较近的 O 形成共价键，再与稍远的 O 形成氢键。氢键有饱和性：已经形成后，第三个负电中心不容易再接上。

第四章 晶体缺陷

理想完整晶体只在绝对零度才存在。缺陷来自两类原因：热涨落把原子赶离格点，以及化学组成偏离理想配比。几何上分成点、线、面。材料性质对缺陷很敏感：钢的杂质、半导体的施主受主、红宝石里的 Cr、高温超导体里的氧空位，课件都拿来当例子。

点缺陷

肖特基缺陷：原子获得足够能量后迁到表面，内部留下空位。产生 n 个空位使内能增加 n uv，排列方式数是从 N 个格点里选 n 个的组合数，熵增加 kB ln Ω。自由能 F = U − TS 对 n 取极小，并用斯特令公式，在 n ≪ N 时得到

n ≈ N exp(−uv / kBT)。

数目对温度极敏感。课件的纯铜例子：uv = 1 eV 时，1000 K 的浓度约 10−5，室温约 10−17，差 12 个数量级。

弗伦克尔缺陷：原子进入间隙，同时留下空位，空位和填隙成对出现。设间隙位置有 N′ 个，形成能是 ui，平衡数目是

n = √(N N′) exp(−ui / 2kBT)。

N′ 可以等于 N，也可以更大。课件举例：面心立方的四面体间隙数是原子数的 2 倍。分母里的 2 来自空位和填隙各贡献一份组合熵，做题时不要写成和肖特基一样的 exp(−u/kBT)。

反位缺陷是化合物里两种原子交换位置。色心是点缺陷或其复合体俘获电子或空穴后产生附加吸收、使晶体着色。电子型色心俘获电子，空穴型俘获空穴。F 心是卤化碱中阴离子空位俘获一个电子；课件还列出 R 心（F3）、VK 心和 H 心。被俘获的电子和周围离子的位形耦合，吸收之后会再发射声子，这是位形坐标模型要讲的内容。

线缺陷：位错

位错用来解释塑性形变。滑移通常发生在原子面密度大的晶面，方向沿原子线密度大的晶向。课件给的室温体心立方金属例子：滑移面 (112)，滑移方向 [111]。刚性同步滑移所需要的切应力远高于实测值，所以实际滑移是局部先动、再扩展开。

  • 刃型位错：位错线与滑移方向垂直，多出半个原子面。已滑移区和未滑移区的交界就是位错线。
  • 螺型位错：位错线与滑移方向平行，没有那层额外的半原子面。位错线移动的方向和原子滑移方向垂直。

伯氏矢量的大小是滑移一步造成的切变量，方向与滑移方向一致。习题第 1、3、4 题都在区分这两类，以及它们和空位、晶界的差别。

面缺陷

课件列了三类：堆垛层错、孪晶界面、晶粒间界。层错出现在密堆积结构，只打乱次近邻的堆垛顺序，最近邻不变，所以能量远低于晶界。晶界是几个原子间距宽的过渡区。取向差超过 15° 算大角晶界。小角晶界可以看成一排位错，间距 D 和伯氏矢量、倾角满足 D = b/θ。

第五章 晶格振动

前面几章把原子放在格点上不动。实际上每个原子都在平衡位置附近振动，而且因为有相互作用，振动是集体的，用格波描述。只有振幅很小、力与相对位移成正比时，各模式才彼此独立，这就是简谐近似。课件同时说明：原子的德布罗意波长约 0.01 Å，所以格点的运动本身仍可用经典力学写方程，量子化的是格波的能量。

§4.1 一维单原子链

只保留最近邻、只保留相对位移的二次项。课件的势能和受力是

Φ = (β/2) Σ (un − un−1)²，　fn = −β (2un − un+1 − un−1)。

β 是近邻力常数，单位 N/m。运动方程 m ün = β (un+1 + un−1 − 2un)。代入行波 un ∝ exp[i(qna − ωt)]，得到色散关系

ω = 2 √(β/m) |sin(qa/2)|。

q = π/a 时频率最高，ωmax = 2√(β/m)。ω 对 q 的周期是 2π/a，和一维倒格矢相同，所以 q 和 q + 2πh/a 描述同一个振动，波矢可以限制在简约布里渊区 −π/a < q ≤ π/a。

长波 qa ≪ 1 时 ω 与 q 成正比，相速度 a√(β/m)，和连续介质里的声速 √(弹性模量/线密度) 相同。这类格波叫声学支。布里渊区边界上群速度 dω/dq = 0，相邻原子相位相反，成为驻波，能量不再往前传。

§4.2 一维双原子链

原胞里有两个原子时，每个波矢对应两支。声学支相邻原子同向振动，振幅比大于零。光学支振幅比为负，相邻原子反向；长波光学支的频率不为零。课件在布里渊区边界比较了光学支两个原子的振幅。离子晶体的长波光学支会和电磁波耦合，这是「光学支」这个名字的来源；单原子链没有光学支。

§4.3 声子

周期边界使允许的波矢分立。每个独立模式是一个量子谐振子，能量是 (n + 1/2) ℏω。多出来的 1/2 ℏω 是零点能。n 增加 1 就是产生一个声子，减少 1 就是湮没一个声子。声子是准粒子，不是可以单独拿出来的真实粒子，数目也不守恒。它是玻色子，热平衡时一个模式的平均声子数是

⟨n⟩ = 1 / (exp(ℏω / kBT) − 1)。

高温时 ⟨n⟩ ≈ kBT / ℏω，和温度成正比。ℏq 叫晶体动量，不是粒子的真实动量。q 与 q 加上一个倒格矢代表同一个声子态：能量相同，晶格振动也相同。

三维、每个原胞 r 个原子时，一共有 3rN 个模式，N 是原胞数。沿布里渊区对称轴，常常可以分成 1 支纵波和 2 支横波。其中 3 支是声学支，其余 3r − 3 支是光学支。态密度和群速度成反比：群速度越小，同样的频率间隔里模式越多。德拜模型的态密度只拟合长波声学支那段抛物线。

§4.7 晶格比热

经典能量均分：3rN 个简正模式在高温下都充分激发，总内能 U = 3rN kBT，比热是常数。这就是杜隆–珀蒂定律，高温下与温度、与具体材料都无关。

  • 爱因斯坦模型（1907）让所有模式共用一个频率 ωE，特征温度 ΘE = ℏωE / kB。它能说明比热在低温下降，但忽略了格波色散，低温降得太快。课件用金刚石的实验作比较。
  • 德拜模型只保留长波声学支，把晶体看成连续介质，纵波、横波各有自己的速度，并用原子总数截断一个最高频率。低温比热按 T3 下降，和实验符合；高温仍回到杜隆–珀蒂定律。德拜温度 ΘD 反映结合的强弱。缺点是色散被简化了，ΘD 实际上会随温度变化。课件有一道例题：用德拜模型求零点振动能。

§4.8 物态方程和热膨胀

简谐近似下，晶格振动的自由能给不出热膨胀：平衡位置不随温度移动。热膨胀来自势能里的高次项，也就是非简谐作用。物态方程里，简谐振动的贡献单独是一项，不能靠它解释体积随温度变化。

§4.9 晶格热传导

简谐近似里声子之间不交换能量，一种频率的声子不能把能量交给另一种，也就没有热阻。非简谐项让声子碰撞：两个声子合成一个，或者一个声子分成两个，同时满足能量守恒和准动量守恒。

声子气用平均自由程 l 和碰撞时间 τ 描写，平均速度 v = l/τ。正常过程（N 过程）的倒格矢为零，声子总晶体动量不变，不直接造成热阻。倒逆过程（U 过程）要加上一个不为零的倒格矢，总晶体动量发生大的改变，这才贡献热阻。只有波矢本来比较大的声子，相加之后才出得了第一布里渊区，才能发生 U 过程。温度升高，声子变多，碰撞变频繁，平均自由程下降。
