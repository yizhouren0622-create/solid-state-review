# 固体物理学复习站

上海大学微电子学院固体物理学部分的梳理和习题页。版式沿用量子力学复习站的纸色静态页：题目、提示、解答分块，解答默认收起。

线上页面：<https://yizhouren0622-create.github.io/solid-state-review/>

## 现在有什么

- `review.html`：按课件小节整理的复习内容。覆盖第二章衍射、第三章结合、第四章缺陷，以及文件名为第五章、课件小节号仍写作 §4 的晶格振动。
- `ex-ch12.html`：第一二章习题 14 题。参考答案可切换中英双语、中文或英语。
- `ex-ch4.html`：第四章习题 5 题。第 5 题的中文按提供的解答转录。语言切换与上一页相同。

提供的材料里没有第一章课件，也没有第三章、第五章习题。第一章只采用第二章课件末尾的「第一、二章要点复习」清单，不另编一套第一章讲义。

## 资料边界

课件和教材 PDF 不放进本仓库。页码按各 PDF 的物理页序。解答是对照课件写出的学习答案，不是教师公布的标准答案。参考答案默认中英对照，页顶可改成只看中文或只看英语。分数用上下分式，e 的幂写成指数，不用 exp。
